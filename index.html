Configurando sua primeira conta, projeto e tabela

Um guia rápido para sair do zero até ter um banco de dados funcionando no Supabase — da criação da conta às chaves de conexão do seu app.

  1. 1
    Criar uma contasupabase.com → Start your project
  2. 2
    Criar um projetoorganização, senha do banco e região
  3. 3
    Criar uma tabelaTable Editor → New table
  4. 4
    Configurar a segurançaRLS e policies
  5. 5
    Pegar os dados de conexãoURL da API e chaves

1Criar uma conta

  • Entre em supabase.com.
  • Clique em Start your project.
  • Cadastre-se usando GitHub, Google ou e-mail.
  • Confirme seu e-mail, caso seja solicitado.

2Criar um projeto

  • No painel, clique em New project.
  • Escolha ou crie uma organização.

Preencha os campos:

CampoO que colocar
NameNome do projeto
Database PasswordUma senha forte
RegionA região mais próxima
PlanPlano gratuito para começar
  • Clique em Create new project.
  • Espere o Supabase preparar tudo.
ATENÇÃO

Guarde a senha do banco em um local seguro — ela não fica salva em nenhum outro lugar visível.

3Criar uma tabela

Uma tabela funciona como uma planilha.

  • Abra Table Editor.
  • Clique em New table.
  • Dê um nome simples, como tarefas.
  • Adicione uma coluna chamada titulo, do tipo text.
  • Mantenha a coluna id.
  • Clique em Save.

4Configurar a segurança

Ative o RLS (Row Level Security) na tabela. Ele funciona como um porteiro que decide quem pode ver ou mudar cada informação.

Depois, crie policies, que são as regras desse porteiro.

IMPORTANTE

Sem essas regras, seu aplicativo pode não conseguir acessar os dados ou pode deixá-los expostos.

5Pegar os dados de conexão

No painel do projeto:

  • A URL da API fica em Integrations → Data API.
  • As chaves ficam em Settings → API Keys.
NOTA

Use a chave pública, como a publishable key ou a chave legada anon, no aplicativo.

PERIGO

Nunca coloque service_role ou uma secret key em código público — elas têm poderes administrativos.

Pronto! Sua conta, seu projeto e sua primeira tabela estão configurados.
